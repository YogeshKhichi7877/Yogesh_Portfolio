## 6. Design System / UI Details

### Main Colors

- **Primary background:** black and near-black (`#000000`, `#0a0514`, `#0a0a0a`).
- **Section backgrounds:** gradients using slate/gray/black, e.g. Tailwind `from-slate-900`, `via-gray-900`, `to-black`.
- **Accent colors:** blue, cyan, purple, pink.
- **Common gradient:** blue to purple (`from-blue-500 to-purple-600`, `from-blue-400 to-purple-600`).
- **CSS variables in `src/index.css`:**
  - `--gradient-primary: #667eea -> #764ba2`
  - `--gradient-secondary: #f093fb -> #f5576c`
  - `--gradient-accent: #4facfe -> #00f2fe`

### Fonts

- Google Fonts:
  - `Inter`
  - `JetBrains Mono`
- Body font uses Inter with system fallbacks.
- JetBrains Mono is imported but not visibly used in the inspected components.

### Layout Style

- Dark, immersive, animated one-page portfolio layout.
- Full-width sections with centered max-width content (`max-w-7xl` or `max-w-4xl`).
- Hero uses a split layout on large screens: text and profile image over a 3D background.
- About, Projects, Education, Contact use grid-based responsive layouts.
- Legal pages use narrow centered content cards.

### Button Style

- Rounded/full pill buttons for navigation filters and hero CTA.
- Gradient-filled buttons for primary actions.
- Border/transparent secondary buttons.
- Hover effects include scaling, color change, glow/shadow, and background transitions.

### Card Style

- Dark glass-like cards with:
  - `bg-gray-800/40`, `bg-gray-900/30`, or gradient dark backgrounds.
  - Backdrop blur.
  - Semi-transparent borders.
  - Rounded corners, commonly `rounded-xl` or `rounded-2xl`.
- Project cards include image headers and hover overlays.

### Animations/Hover Effects

- GSAP entrance animations for major sections.
- ScrollTrigger animations for About, Education, and Contact.
- Hero parallax and profile image floating animation.
- Project card hover scaling, image zoom, overlay reveal, and title color change.
- Skill/stat hover and count-up effects.
- Custom cursor on desktop.
- CSS keyframe animations for gradient, floating, spin, pulse glow, loader dots, loading bar, particles, and orbiting elements.
- React Three Fiber scenes animate Jupiter, GLB logo model, footer map, sparkles, and particles.

### Responsive Design Behavior

- Tailwind responsive classes are used extensively (`sm:`, `md:`, `lg:`, `xl:`).
- Navigation:
  - Desktop shows full nav.
  - Mobile uses hamburger menu.
  - Mobile navbar visibility logic changes after scrolling half a viewport.
- Hero:
  - Stacks vertically on smaller screens.
  - Uses smaller profile image and text sizes on mobile.
- Project grid:
  - 1 column by default.
  - 2 columns at medium screens.
  - 3 columns at large screens.
- Education timeline:
  - Left timeline on mobile.
  - Alternating timeline cards on desktop.
- Contact:
  - Single-column on smaller screens.
  - 5-column grid on large screens.

### Overall Visual Theme

Dark futuristic creative-tech portfolio with 3D space visuals, glassmorphism, neon blue/purple gradients, animated interactions, and developer-focused content.

### Code Organization Concerns

- Large blocks of old commented-out code remain in `App.tsx`, `About.tsx`, and `src/lib/three-setup.ts`.

- `Projects.tsx` mixes project data, filtering, animations, and card rendering in one large component.
- `Education.tsx` mixes education data, certification data, skill data, animation setup, and DOM event listeners.

### Accessibility Concerns

- Some icon-only social/action links do not have accessible labels.
- Some clickable anchors have `href="#"`, which is not meaningful for screen readers or keyboard users.
- `body` has `user-select: none`, which prevents users from selecting/copying text.
- Custom cursor hides the default cursor on desktop; this may affect accessibility if not carefully tested.
- Animations are widespread, although a `prefers-reduced-motion` CSS media query exists.
- Contact form success is visual state only; no live region was found for assistive tech announcement.

### Mobile/Responsive Concerns

- The site uses many responsive Tailwind classes, but 3D canvases, large images, and hover effects may need real-device testing.
- Navigation uses `window.innerWidth` inside render logic/class logic. It will not automatically update if viewport changes without scroll/state changes.
- Some long text labels, project names, and timeline content may need mobile visual QA.

### Performance Concerns

- Large assets:
  - `yjk2.glb` is about 5.4 MB.
  - `8k_jupiter.jpg` is about 3.1 MB.
  - `cooding.png` is about 2.5 MB.
  - `yk_logo2.png` is about 1.36 MB.
- Multiple active 3D scenes and GSAP animations can be heavy on low-end devices.
- Google Fonts are imported both in `index.html` and `src/index.css`, causing duplication.
- Randomized particles/map points in render-time code can cause visual inconsistency between loads.

### Console/Runtime Risk

- `About3D.tsx` uses `window.devicePixelRatio` during component render. This is fine in browser-only Vite rendering, but would be unsafe in server-side rendering.
- `Navigation.tsx` uses `window.innerWidth` in JSX class logic. This is browser-only and may be brittle during resize.
- `Education.tsx` attaches mouse event listeners directly to `.education-card` elements and does not remove them in cleanup.
- Some direct DOM animation/event patterns may become fragile if components re-render or content changes.

## 13. Final Summary

This website is a React/Vite/TypeScript personal portfolio for Yogesh Khinchi. The home route is a single-page scrolling portfolio composed of hard-coded React section components. It uses Tailwind CSS for styling, GSAP for animations, Lenis for smooth scrolling, Lucide for icons, and React Three Fiber/Three.js for 3D visuals. Legal pages are separate React Router routes.

- `src/components/About.tsx`: about text, skill cards, stats.
- `src/components/Projects.tsx`: full project inventory and project filters.
- `src/components/Education.tsx`: education, certifications, technical skills.
- `src/components/Contact.tsx`: contact info and contact form UI.
- `src/components/Footer.tsx`: footer content and legal links.
- `src/index.css`: global styles, fonts, animations, scrollbar, accessibility media queries.
- `index.html`: SEO metadata, favicon, canonical, Open Graph/Twitter tags, JSON-LD.
- `vite.config.js`: PWA config and build plugin setup.
- `public/`: images, model, resume PDF, sitemap, robots file.
